
# GenAI Resume Assistant

## Project Overview
An AI-powered Resume Assistant built using
Python, Streamlit and Google Gemini API.

## Features
- Resume Analysis
- AI Resume Improver
- Job Description Matching
- AI Interview Question Generator
- Downloadable Resume Analysis Report

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- PyPDF
- Python-docx
- Pandas (optional future extension)

## Installation

1. Clone the repository.

2. Create virtual environment:

   python -m venv .venv

3. Activate environment:

   .venv\Scripts\activate

4. Install dependencies:

   pip install -r requirements.txt

5. Create .env file:

   GEMINI_API_KEY=your_api_key

6. Run application:

   streamlit run app.py
